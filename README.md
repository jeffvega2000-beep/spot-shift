# Spot Shift

A small puzzle game for GitHub Game Off 2026 (theme: **SHIFT**). By Jey Jey.

Spot wants to go to bed. Shift the moon: pale tiles exist only in moonlight, dark tiles only in shadow. Cats take one step every time you shift.

- **Walk:** arrows or WASD · **Shift the moon:** Shift or Space · **Undo:** Z · **Restart:** R · **Next level:** Enter
- 10 levels, English and Spanish, touch buttons. No libraries: open `index.html` in a browser.
- `reglas.js`: rules and solver · `generar.js`: level generator (every level is solver-checked).
